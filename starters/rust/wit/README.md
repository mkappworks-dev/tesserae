# tesserae:mods@0.3.0

The Tesserae Mod contract, contract line **0.3**, copied verbatim from the
Engine's published `wit/0.3` directory. Do not edit it: a component built
against an altered copy is refused at load.

MIT licensed, so a proprietary Game may ship it. Patch releases of the line
(`0.3.x`) change comments and clarifications only and stay compatible; a
breaking change to a record or variant is a new line (`0.4`), never a `0.3.x`.
