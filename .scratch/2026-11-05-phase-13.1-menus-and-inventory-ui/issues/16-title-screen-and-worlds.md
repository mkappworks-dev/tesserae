# 16: Title screen and Worlds

Status: done

Blocked by: None (can start immediately)

Spec: [Phase 13.1](../spec.md).

## What to build

The launcher opens on the title screen: the engine's mosaic mark and wordmark, Continue (naming the last World and Game), Your Worlds, Create a World, Mods and Settings. Worlds lists each World with its Game, Voxel size and last played, with search by name or Game and Play and Edit side by side. The Mods library lists installed Mods. Keyboard and controller navigation follow the prototype. The look follows the prototype's Cinematic theme.

## Acceptance criteria

- [x] Continue opens the last played World.
- [x] Search filters Worlds by name or Game.
- [x] Every screen is usable by keyboard alone.
- [x] Existing World list journeys (open, rename, delete, trust) still work.
