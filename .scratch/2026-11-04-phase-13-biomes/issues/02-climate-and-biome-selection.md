# 02: Climate and Biome selection

Status: done

Blocked by: 01

## What to build

The generator can answer which Biome a column belongs to. Climate is temperature and humidity fields from value-noise fbm, sized in metres, and a Biome is a point in the temperature/humidity square. The nearest point wins and the border is warped by low-frequency noise. `biome_at(x_m, z_m)` and the Climate values are a Server-only query on the generator in `tesserae-core`, not in WIT. No visible change yet.

## Acceptance criteria

- [x] Biome selection is a pure function of seed and metres: the same answer at every Voxel size and for every LOD level generator.
- [x] Selection at known Climate points picks the expected Biome; the warped border is irregular and deterministic.
- [x] The generator stays Send + Sync and cheap to construct per level.
- [x] `tesserae-core` still depends on neither Bevy nor wgpu.
