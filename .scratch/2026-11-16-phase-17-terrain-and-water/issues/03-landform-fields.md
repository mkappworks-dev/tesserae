# 03: Landform fields and base height (17a)

Status: ready-for-agent

Blocked by: 01, 02

Spec: [Phase 17](../spec.md).

## What to build

Continentalness, erosion, peaks-and-valleys and ruggedness as warped 2D fields in metres, mapped by curves to a base height inside the band: plains, hills, plateaus, mesas, canyons, badlands, volcanic cones and ranges with snow-capped peaks. Tuning is declared by a Game; the kinds are fixed.

## Acceptance criteria

- [ ] Same Voxels in any Chunk order and at 1.0, 0.5 and 0.25 m.
- [ ] Every height lies in the band.
- [ ] A screenshot of each landform is reviewed.
