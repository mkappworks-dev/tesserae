# 05: More shared data Mods, solids and fluids

Status: done

## What to build

Add timber, brickwork, lamps, wool, frost, crystals and bog as data Mods with original generated textures, each documented, validated and packaged, with a test that loads them all together.

## Acceptance criteria

- [x] Every Mod validates and packages with the real commands.
- [x] Fluids, reactions and fuel in bog resolve across Mods.
- [x] A test loads all twelve Mods together.
- [x] Each Mod has a README and appears in docs/demo-games.md.
