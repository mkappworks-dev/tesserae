# 02: Trust the whole set in one step

Status: ready-for-agent

## What to build

One Trust screen lists every untrusted item, groups data Mods apart from components, and grants all with one action. The wording matches what runs.

## Acceptance criteria

- [ ] "Trust all N and create" grants every listed item and opens the World.
- [ ] Data Mods say they run no code; a component says it runs code.
- [ ] Cancel grants nothing.
