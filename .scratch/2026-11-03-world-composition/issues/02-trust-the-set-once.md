# 02: Trust the whole set in one step

Status: done

## What to build

One Trust screen lists every untrusted item, groups data Mods apart from components, and grants all with one action. The wording matches what runs.

## Acceptance criteria

- [x] "Trust all N and create" grants every listed item and opens the World.
- [x] Data Mods say they run no code; a component says it runs code.
- [x] Cancel grants nothing.
