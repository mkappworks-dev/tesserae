# 04: Add the tidewater Game

Status: ready-for-agent

Blocked by: 01

## What to build

Add `games/tidewater`: islands and shallow seas on strata, waters and flora. The sea level rises and falls slowly through Commands from `tick`.

## Acceptance criteria

- [ ] The tide moves within declared bounds and never drowns the Player's spawn; a test checks both.
- [ ] World parameters (sea level, caves, smoothing) are exercised.
- [ ] README covers behaviour, dependencies and how to run it.
