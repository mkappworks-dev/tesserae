# 03: Add the ember Game

Status: ready-for-agent

Blocked by: 01

## What to build

Add `games/ember`: a volcanic highland on strata, waters, flora and hearth. Lava vents erupt on a timer from `tick`, and water meeting lava makes obsidian through the shared reactions.

## Acceptance criteria

- [ ] Vents erupt on the declared timer, and a test observes an eruption.
- [ ] Wood burns and leaves ash through hearth's rules.
- [ ] README covers behaviour, dependencies and how to run it.
